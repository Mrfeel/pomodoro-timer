# Word 数学文档格式规范

用户对《线性代数第七章_详尽讲解》的文档格式非常满意，要求以后涉及数学公式的 Word 文档都按照此格式编辑输出。

**Why:** 用户明确表示喜欢该文档的排版风格，希望统一所有数学类 Word 文档的格式。

**How to apply:** 生成数学类 Word 文档（.docx）时，先编写 Markdown 源文件遵循以下格式规范，然后用 python-docx 脚本转换为 Word 文档。

## 源文件格式（Markdown → python-docx → .docx）

### 1. 文档头部
```markdown
# 课程名 第X章：章节标题

> 基于课堂 PPT (学期信息) | 杨思辰 · 未来技术学院 · 物理学专业
>
> 🔥 考试重点：**关键词1、关键词2、关键词3**
```

### 2. 目录
- 使用有序列表链接到各节锚点
- 格式：`1. [§1 节名](#sec1)`

### 3. 章节结构
- **一级标题（章）**：`# §N 章名 {#secN}`，前后用 `---` 分隔
- **二级标题（节）**：`## N.M 节名`
- **三级标题（小节）**：`### 📝 例 N` 或 `### 小标题`

### 4. 数学公式
- **行内公式**：`$...$`
- **独立公式**：`$$...$$`
- **重要公式（加框）**：`$$\boxed{...}$$`
- **多行对齐**：`$$\begin{aligned}...\end{aligned}$$`
- **矩阵**：`$$\begin{pmatrix}...\end{pmatrix}$$`
- **行列式**：`$$\begin{vmatrix}...\end{vmatrix}$$`

### 5. 强调/提示块（使用 blockquote `>`）
- `> 💡` — 直观理解、通俗类比、记忆技巧
- `> ⭐` — 核心重要结论、定理
- `> 🔥` — 考试/小测重点
- `> ⚠️` — 注意事项、常见错误

### 6. 例题格式
```markdown
### 📝 Example N（描述性标题）

> 题目内容（blockquote 或直接文字）

**解：**

**第1步：** ...

**第2步：** ...
```

### 7. 定义/定理引用
- 格式：`**(Definition X.X)**` 或 `**(Theorem X.X)**`
- 关键术语首次出现时加粗

### 8. 表格
- 使用 Markdown 表格，简洁清晰
- 适合对比、分类、速查等场景

### 9. 文档结尾
```markdown
# 📋 小测重点速查卡片 {#cheatsheet}

（公式卡片、核心定理表格等快速复习内容）

---

<div style="text-align: center; ...">

—— 祝考试顺利！——

</div>
```

### 10. 文字风格
- 使用简体中文
- 语气亲切但不失严谨（"想象你在搭积木"）
- 每个重要概念配合直观解释
- 公式推导步步展开，不跳步
- 适当使用 emoji 增强可读性（📝📋💡⭐🔥⚠️）

## Word 生成要点
- 使用 python-docx 库
- 标题用 Word 标题样式（Heading 1/2/3）
- 公式用 LaTeX 渲染后嵌入（或使用 Word 内置公式编辑器）
- blockquote 转为带左边框的缩进段落，背景可加浅色
- 表格加边框
- 代码块用等宽字体
